这是当前手机端布局与交互的阶段版本，供团队预览和继续讨论。桌面入口、球形馆藏，以及 `library/wendao/`、`library/hongqi-revised/` 的已有内容保持不变。

- [移动端首页](./index.html)

从仓库根目录启动静态服务器，例如：

```sh
python -m http.server 4174
```

然后打开 `/mobile/` 或 `/mobile/preview.html?focus=about`。无需安装依赖或构建。

## 当前可体验的流程

1. 横向滑动或拖动连续书架，选择图书并打开详情。
2. 向下阅读研究中心介绍：分隔线与文字随滚动逐行出现；介绍位于书脊区域之前。
3. 点击任一本书脊：书本转出封面，整屏变为该书配色，同一本书连续移动到对应的介绍页。书脊不使用鼠标悬停抬升效果。
4. 在详情页展开内容简介、目录或摘录；加入阅览台，再从阅览台打开。
5. 在书库中按书名、作者、年份检索，筛选主题或按出版时间排序。

阅览台记录保存在当前浏览器的 localStorage，使用独立键 `drc-mobile-reading-desk-v1`。

## 文件与资源

- `index.html`：移动页面入口。
- `mobile.css`：响应式排版、书架、介绍区和过渡样式。
- `mobile.js`：路由、检索、阅读台及介绍区滚动显现。
- `data.js`：沿用原 ZIP 中的书目与介绍内容。
- `book-renderer.js`：从原站适配的 Canvas2D 精装书渲染。
- `spine-interaction.js`：书脊、封面与介绍页之间的连续转场。
- `preview.html`：320 / 390 / 430 px 预览框。

封面、标志和字体直接复用 `../library/assets/`，不重复提交资源。所有资源地址均为相对路径，可在 GitHub Pages 的仓库子路径下使用。

## 阶段范围与验证

此版本用于同步进度，尚未把球形馆藏、桌面时间线和全部深度章节转成手机布局。书目内容是当前原型快照；后续可继续与主站数据及其他同学的移动章节整合。

已在浏览器中检查 320 / 390 / 430 px 布局、书架操作、检索与空结果、保存和重新打开、介绍区滚动显现，以及书脊到详情的深浅配色转场。尚未完成真机触摸与不同浏览器测试。
